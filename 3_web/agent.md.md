# parametric sandbox web

## objectives:

- document and share custom grasshopper components for user access online

## main elements

- simple list of components (text only) sorted by category/type
- when a component/script title is clicked, a dropdown is revealed showing a brief 3-5 sentence description of the component (maximum, some may have fewer than 3) as well as the .png image associated with it. if there is not a .png named the same as the .py, skip the image.
- the top menu should have a few simple options/links:
    - home
    - project GitHub
    - download app (this should be a .zip named "alexandria_app.zip" which contains the 0_scripts and 1_userobjects folders)

- design should be simple and fonts legible, keep colors to a minimum.
- design should be flexible so that the entire site can be seen easily and cleanly on a small/mobile browser

- the site should be self-contained inside the 3_web folder, with the exception of media and downloads which may live elsewhere
- provide the information needed to host on render including output folder path and build command
